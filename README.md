# IT Manager

Il responsabile IT di una PMI italiana: inventario, VMware, Microsoft 365 e Windows, firewall e rete, storage e backup sani e sicuri, con gli strumenti ufficiali, la documentazione e gli avvisi di sicurezza dei vendor, e chiede prima di toccare la produzione.

_The IT manager of an Italian SMB: keeps the inventory, VMware, Microsoft 365 and Windows, firewalls and network, storage and backups healthy and secure, with the vendors' official tools, documentation and security advisories, and asks before touching production._

Modello di agente per Nadia, l'app di nadicode. Si installa dalla Libreria del Portale o da
**Nuovo agente** in Nadia.

## Skill

- `backup-e-storage`
- `fonti-ufficiali-vendor`
- `gestione-incidenti`
- `microsoft-365-e-windows`
- `onboarding-it`
- `rete-e-firewall`
- `sicurezza-e-conformita`
- `vmware-vsphere`

## Attività pianificate

Arrivano in pausa: si attivano in **Attività pianificate**.

- Avvisi di sicurezza della settimana (`0 8 * * 1`)
- Controllo backup (`30 8 * * 1-5`)
- Fonti dei vendor e scadenze (`0 9 1 * *`)
